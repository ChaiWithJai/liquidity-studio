# Private native editor artifact

The manual **Private native editor artifact** workflow assembles the current Studio bridge, pinned Doory editor `27b6f68221fdbf1ef1bedc182e303210ca9e39f5`, and existing locked React/Fabric/ONNX Runtime Web dependencies on hosted CI. It does not run a model, convert weights, launch a browser or deploy anything. Default original-only builds remain unchanged.

Dispatch with the exact reviewed Studio commit and confirmation `PRIVATE_LOCAL_REVIEW`. Download the short-lived artifact from that authenticated workflow run. Verify `provenance.json` against that commit, all listed output hashes and the launcher-manifest hash before placing its `dist` in a private local directory. It records every tracked Studio source blob, every prepared upstream source hash, installed dependency versions/integrities, preserved dependency notices and actual emitted files. The launcher independently checks the bridge hashes and every served file. Its source contract includes the cutout availability helper and native size presets; stale artifacts remain rejected.

Use the existing developer launcher with `--native-assets /absolute/private/artifact/dist --cutout-model /absolute/private/retained-model.onnx`. The model is separately configured and digest checked; no weights or portraits are included in the artifact. Retain the existing Apache model notices with any separately supplied model. A successful build is not cutout acceptance: ordinary Neo must upload an owned image, remove its background, inspect alpha, Undo, save and reopen while preserving original bytes.

This is a private evaluation artifact, not a public release or license clearance. The exact upstream Attribution Assurance License and launch-time attribution remain present. Upstream has now supplied [verified signed license text](investigations/doory-signed-license/README.md). The retained artifact still needs reconciliation with that exact signed license, contributor/NOTICE and dependency notice basis; this recipe does not authorize public redistribution. Dependencies retain their available license/notice files and bundled legal comments. The existing Xenova model's original-checkpoint conversion lineage remains qualified; bundling its runtime does not establish that lineage. No audio or sound-rights acceptance follows.

The private Vite build applies the existing PR78 VideoResult effect correction after verifying the pristine pinned source: a Promise-valued `scrollIntoView` result is discarded, so Change settings/closing the completed export does not become invalid React cleanup. The transform is exact-hash and exact-anchor checked, is excluded from original-only builds, and its script hash is bound by the launcher manifest. This is an attributed host transform, not a claim that the pristine upstream already contained the fix.

The same private build applies PR83's existing exact WebM container patch and byte-identical duration helper. It preserves the actual final video/audio chunk end in the finalized WebM Duration field, rather than truncating a 900-frame video at its last frame's start timestamp. The pristine upstream container, reviewed patch digest and each patch anchor must match. The launcher binds the transform, helper, upstream inventory, patch, Vite config, frame, build entry, package and lock inputs. A rebuilt artifact is required; this does not change any running artifact or establish a fresh MP4/WebM acceptance result.
