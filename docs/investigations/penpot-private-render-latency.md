## Bounded follow-up

The implementation deduplicates only raw managed-account lookup promises within two separate server-injected authority phases: resolve/authorize before official file ACL read, and a fresh resolve/authorize phase afterward. It never caches `authorizeJobActor` results. Every invocation still reads the current local principal/allowlist and compares the original approval timestamp against the provider record; membership, source, binding, image-generation and native ACL checks remain.

Each phase creates a new per-GoogleIdentity-instance asynchronous context, keyed by normalized email, and clears it on exit. A second phase and a different HTTP request always obtain a fresh provider record. Jobs outside these explicitly scoped media-read phases retain fresh lookups. Provider changes after the final lookup still have the ordinary authorization/response race; there is no claim of instantaneous revocation. No public asset exemption, internal-IP trust, shared operator cookie, global positive cache or resource lease is added.

Authored hosted regressions cover28 local checks with two provider lookups, concurrent-request isolation, provider disable/revocation between phases, local-principal and approval-time changes within a phase, provider failure, and no reuse by later requests or ordinary jobs. They have not been run locally under the Neo-only constraint. Exact-head CI, actual repeated timing and actual native pixels remain separate gates. Cultural image coverage and independent archive/image/font recovery remain open, as does standalone SVG resource embedding.

## Bounded relay embedding implementation, awaiting hosted and actual acceptance

The existing single-object SVG relay now prepares data-URI resources after strict SAX inspection, using directly pinned `saxes6.0.0` bytes already present locally. It preserves original source text and attributes with offset replacements, rejects DTD/entities, active elements, event attributes, CSS escapes/imports, duplicate/conflicting attributes and unknown resource URLs, and admits only exact registered native image/font paths. Ordinary fragment paint references remain. There is no arbitrary resource fetch or new upstream fork.

Each resource requires current native cookie/file ACL plus current Studio source, brand, membership, registration and immutable byte hash. Persisted native font variants must supply operator-verified `persistedByteHashes` keyed by their existing `ttfFileId`, `otfFileId`, `woff1FileId` or `woff2FileId`; the source TTF hash does not stand in for generated WOFF/OTF hashes. Missing hashes explicitly reject portable SVG. Existing image actions use their saved immutable source hash, and legacy media additionally requires a registered MIME declaration.

Limits are eight resources,512KiB each,2MiB total decoded resources,1MiB original SVG and6MiB final SVG. The existing6MiB PNG contract is unchanged. No receipt becomes readable until output parsing, embedding, final hash and current authority checks finish. The existing receipt stores original and final SHA plus the exact resource inventory, never native cookies, bearer codes or image/font payloads.

The browser receives a fixed same-origin `/__studio_native_embedded_svg/UUID` URL. Every read reauthorizes the presented native owner and current source/native version, obtains only the recorded original output through a one-use server-only relay, checks the original hash, deterministically embeds the exact recorded resources, checks the final hash and rechecks current authority. Original SVG IDs are excluded from ordinary by-ID receipt delivery so unembedded bytes cannot be served under the embedded hash. Expiry, missing original output or changed resources fail closed; there is no new payload store, positive authorization cache or background cleanup. PNG delivery remains unchanged.

Authored constructor/pure regressions cover exact text/attribute preservation, malicious/malformed input, immutable resource bytes, owner/context drift, changed original outputs, expiry and repeat deterministic reads. They are hosted-only under the Neo-only local constraint. Actual standalone SVG glyph/image fidelity, both-brand raster painting and independent archive/font recovery remain open acceptance work.
