# Explicit Penpot native adapter acceptance

This slice implements a pure, optional Penpot 2.18.3 native changes compiler against the issue 51 versioned specification. It is not wired into production routes, external identity mapping or final sign-off. Existing source approval and organization/brand checks remain the upstream caller's responsibility; plugin-data is provenance, never access authority.

The compiler emits native text, frame main components, active color tokens and appliedTokens fill references. It preserves all logical layer IDs, full source campaign and page semantic notes/field mappings. Visible supplementary copy includes takeaway, sticker prompt and reel hook/CTA; visual instructions remain nonexecuted notes. An invisible subject rectangle is an explicitly unexecuted placeholder. Curved text, cutout, animation, video and external assets are unsupported and required unsupported capabilities reject. Reel output is three static boards with 0–3/3–15/15–30 timing, not a video.

## Actual local model and font evidence

The official local RPC saved two new disposable QA files, one per brand, each with nine pages: one 1080×1350 feed, four 1080×1350 carousel, one 1080×1920 story and three 1080×1920 reel boards. Independent GET verified 50 native text shapes, 9 main components, 0 svg-raw and active Studio/Brand theme with four resolved color bindings. Every logical layer ID and complete source campaign survived in the saved native model. [Sanitized model evidence](54-native-model-evidence.json) records dimensions/timing and bounds; it is not a browser/archive acceptance claim.

Existing repository fonts/notices were uploaded only to the disposable QA team through official 2.18.3 create-upload-session/upload-chunk/create-font-variant commands. Official get-font-variants confirmed Mona Sans 400/700, Inter 400 and Instrument Serif 400. Authenticated original-font asset GETs returned exact SHA256 matches to all four uploaded OTF/TTF source files; [byte evidence](54-font-byte-evidence.json) records hashes and notice references. No new fonts or weights were downloaded. Mona and Inter are OFL 1.1 according to their retained notices and official [Mona repository](https://github.com/github/mona-sans/blob/main/OFL.txt) / [Inter license](https://github.com/rsms/inter/blob/master/LICENSE.txt). Instrument Serif has its separate retained OFL notice. Font-byte availability and native font IDs do not alone prove visual shaping, every glyph, export font embedding or cross-install portability.

Focused Node 22 tests pass for both brands/all pages, source immutability/semantic preservation, native components/no raw-SVG fallback, palette revision with stable IDs, negative versions/dimensions/fonts/capabilities/assets/timing. The local reproducer is documented in the [adapter scope](../specs/penpot-native-adapter.md). No paid model call, cloud resource, browser internals or existing application mutation occurred.

## Actual native archive parser roundtrips

The operator downloaded the CWJ nine-page native `.penpot` archive through the real UI. Its 185,789 bytes/101 entries/SHA256 `60cf389ec3b2fd2ceee6b380cff2ba00dfcce1e321d9f2efc9d8fe70475bf072` were uploaded unchanged to the official local multipart `import-binfile` RPC, creating a separate same-owner file. This was actual native ZIP parser execution, not rebuilding a document from the JSON DTO. The finance nine-page file separately completed official `export-binfile` SSE, actual archive download and the same native import parser.

Independent original/restored GET comparisons for [CWJ](54-cwj-archive-evidence.json) and [finance](54-finance-archive-evidence.json) found identical page IDs/order, fifty native text objects/nine main components, tokens/active sets and complete native shapes after only expected file-ID remapping and correctly matching added per-shape pageId normalization. The CWJ archive retained the human-edited heading and restored source palette. Native plugin-data retained semantic source copy/provenance. No original document was deleted or replaced.

Both archives contain **zero OTF/TTF/WOFF font binaries**. Fonts remain accessible because these restores share the already provisioned QA team. This proves same-team native model roundtrip, not a self-contained fresh-install font/archive package; visual restored rendering and all-format export pixel fidelity still need browser checks. The reusable local reproducer supports `--export-file` and `--archive` with fixed loopback target, explicit owned anchor project, private output and SSE error/completion validation.

Two exploratory request failures were corrected and are not counted as successes: `include-libraries:true` plus `embed-assets:true` returned an SSE error despite HTTP 200 because they are mutually exclusive; multipart version string `3` returned 400, so import uses the documented default native version 3 by omitting that field. Native document/archive version and shared Studio contract schema remain distinct.
