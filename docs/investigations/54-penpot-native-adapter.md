# Explicit Penpot native adapter acceptance

This slice implements a pure, optional Penpot 2.18.3 native changes compiler against the issue 51 versioned specification. It is not wired into production routes, external identity mapping or final sign-off. Existing source approval and organization/brand checks remain the upstream caller's responsibility; plugin-data is provenance, never access authority.

The compiler emits native text, frame main components, active color tokens and appliedTokens fill references. It preserves all logical layer IDs, full source campaign and page semantic notes/field mappings. Visible supplementary copy includes takeaway, sticker prompt and reel hook/CTA; visual instructions remain nonexecuted notes. An invisible subject rectangle is an explicitly unexecuted placeholder. Curved text, cutout, animation, video and external assets are unsupported and required unsupported capabilities reject. Reel output is three static boards with 0–3/3–15/15–30 timing, not a video.

Instrument Serif has its separate retained OFL notice. Font-byte availability and native font IDs do not alone prove visual shaping, every glyph, export font embedding or cross-install portability.

Focused Node 22 tests pass for both brands/all pages, source immutability/semantic preservation, native components/no raw-SVG fallback, palette revision with stable IDs, negative versions/dimensions/fonts/capabilities/assets/timing. The local reproducer is documented in the [adapter scope](../specs/penpot-native-adapter.md). No paid model call, cloud resource, browser internals or existing application mutation occurred.
