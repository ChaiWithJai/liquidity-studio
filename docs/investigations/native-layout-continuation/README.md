# Continuing an imported human layout

This increment adds a deliberate continuation into a **new native proposal** after
the current founder reviews and promotes the retained campaign copy. It keeps the
historical native document unchanged. Human wording, object IDs, geometry, notes,
and page timing survive; compatible current Brand Kit tokens are applied. No old
layout approval, export grant, or clinical authority transfers to the new copy.

The entry is Campaign Studio → Saved native layouts → Open selected layout →
Continue saved layout. Review the current campaign copy when required, check the
reviewed source, then create an editable copy. Incompatible fonts, missing owned
assets, changed versions, or changed access are refusals requiring reconciliation.

## Verification boundaries

Before the later browser-only testing constraint, five backend regression groups
passed, including both presets × four formats, old-record preservation,
idempotent recovery, and source/identity/asset/font/version races. Five compiled
Studio browser cases also passed. These runs preceded the final combined merge
and the task-copy adjustment; they are not a claim of a fresh full-suite run on the
final release head.

Subsequent interactive acceptance uses only the existing BrowserOS Neo profile,
one controlled password-fixture hostname at a time. The fixture was constructed
through real prepare/review, native save, portable export, and fresh-scope install
services. It uses a nonclinical controlled source, no model call, and no maintained
Google account or production data. The current licensed private native frame is
reused without publishing or rebuilding its upstream-containing assets.
The fixture uses isolated in-memory SQLite stores: page reload checks saved
service state, rather than process-restart or disk-recovery durability.

Native-menu PNG downloads demonstrate editable proposal pixels. They are distinct
from a new exact-version Studio approval and verified PNG export. Static reel
boards do not establish video export. This increment does not establish a hosted
rollout, provider acceptance, commercial license clearance, or the whole of issue
#57.
