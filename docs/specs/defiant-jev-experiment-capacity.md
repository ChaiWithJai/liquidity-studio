# Configured evaluation experiment capacity

The organization-wide saved-result list must not disable a separate configured account experiment. The server list transaction reads the constructor-owned account budget alongside identity, strategy and index, validates its existing shape, and returns only `attemptConsumed`. It preserves all saved records and does not return budget identities or grant execution authority. The existing transactional adapter may materialize JSON null when reading a missing budget; this is not an initialized budget, reservation, refund or reset. No physical absence or zero-storage-write guarantee is made. Missing or null budget means unconsumed; malformed budget fails closed. UI keeps unknown capacity distinct from consumed, requires discovery executionAvailable strictly true and capacity explicitly false before a new Run, while same-key recovery remains available. POST reservation, account scope, authority and one-attempt limits remain unchanged.

Source: server/defiant-jev-durable.js and ClaimEvaluations.svelte. Hosted Node contracts cover separate experiments, prior records, cross-organization consumption, malformed budget and revoked authority; browser contracts cover prior-record enablement, consumed reload disablement and retained same-key recovery. No dependencies or configuration changes. Use existing hosted Verify Node and Chromium jobs; no local application execution. This fixes a pre-dispatch UI blocker and does not claim a model result.
