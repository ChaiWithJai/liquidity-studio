# Editor contract v1 (#51)

Objective: expose an optional, authenticated inspection specification derived from one scoped repository snapshot. It is not a native document, editor connection, rendering acceptance or publishing approval. Existing exporter stays unchanged when disabled.

Interface: injected MultimodalCanvasPort.compileMultimodalBundle receives trusted scope, profile, story and validated query. GET /api/studio/multimodal-spec requires schemaVersion=1, storyId, expectedRevision, generationId, expectedBrandRevision and optional format. Bootstrap exposes brandRevision, computed from canonical profile JSON. Both DooryDocument schema1 at pinned commit and Penpot2.18.3/archive1 are target descriptors only. No native payload, arbitrary URL, credential or network operation is accepted.

Authority: Studio owns source approvals, profile tokens and revisions. External edits are proposals; reapproval is required before adoption. Optional parallel governance review precedes ordered finishing and final sign-off. Neither review nor a specification means factual truth or automatic clinical approval. All requested stable layer IDs remain on each proposed page; missing assets remain explicit placeholders. Four formats include four carousel pages and exactly three reel pages at0–3/3–15/15–30 seconds. Native capabilities remain unsupported until implemented and verified; no flattening fallback.

Implementation: pure server/multimodal-contract.js; DI boundary in container.js; scoped route in index.js. Existing Node22 node:test suite covers schema/native versions, stale scope/content/profile/source, page counts/layers/tokens, capabilities and authenticated HTTP routing. No dependency or database migration. Canonical v1 accepts identity migration only; unknown versions reject explicitly, never reinterpret Fabric data as Penpot or vice versa.

Commands: `cd liquidity-studio && node --test server/multimodal-contract.test.js`; full `node --test server/*.test.js` before PR. Use readable named functions, 2-space indentation and immutable input snapshots. Never contact an editor, approve a clinical claim, flatten unsupported layers, provision infrastructure or mutate running pilot processes. Feature flag STUDIO_EDITOR_CONTRACT_ENABLED=true enables inspection only; unset disables route. Rollback disables flag. Current source, API and module scope are already authorized by the issue delivery instruction.

## Inspection example and downstream boundary

First call the existing authenticated bootstrap with organizationId and brandId; retain its brandRevision and selected story's revision/generationId. Then GET `/api/studio/multimodal-spec?organizationId=...&brandId=...&schemaVersion=1&storyId=...&expectedRevision=...&generationId=...&expectedBrandRevision=...`. Omit format for all four formats. Optional nativeTargets is JSON matching the exact returned target descriptors; optional requiredCapabilities must be an empty JSON array until a native adapter is available. Duplicate and unknown query keys reject. No external endpoint is accepted. A profile edit changes the hash; refresh bootstrap before retrying a409.

The contract is an adapter-neutral proposal, not Fabric JSON or a Penpot archive. Reel layout timing0–3/3–15/15–30 is explicit; sourceBeatTimecode preserves the current campaign's original timing for audit rather than rewriting it. Empty metric cards and missing cutout assets are explicit placeholders; animations and cutouts have not executed. Native capabilities return unsupported; requesting one fails422 rather than flattening the output. Source excerpts must still match the saved source-backed generation; edited campaigns that violate the current integrity contract reject until reviewed/regenerated.

Only known v1→v1 identity migration exists. It returns a clone; no historical native payload is guessed or converted. Future schema migration and editor adapters require separate versioned validation and actual acceptance. Upstream: scoped identity/repository, approved claims, campaign provenance and Studio-owned profile. Downstream: #52–#58 adapters/security/governance; this does not complete those tickets or #39. ADR59's accepted adapter strategy must be respected; no assumption that Studio must host either editor or give it credential authority.

Validation on the isolated implementation: Node22 backend suite92passed/1intentional emulator skip; contract tests include both presets, exact token values, sources/clinical quarantine, stale/foreign state, versions/capabilities, unchanged inputs, real authenticated HTTP and feature-disabled404. No browser/native acceptance or current runtime deployment is asserted by these tests.

The response carries a deeply frozen, cloned sourceCampaign snapshot of the entire validated persisted campaign. Every page includes semanticContent.format (all copy, captions, layout/visual notes and timing for that format), semanticContent.page and explicit leaf sourceFieldMappings. These preserve source fields independently of the small stable-layer rendering proposal; notes and timings are not evidence of executed media. The HTTP JSON representation is a snapshot, not a client-edit authorization. The disabled flag is documented in .env.example.
