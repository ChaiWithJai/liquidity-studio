# Defiant OS: real evidence to a useful decision

## Current direction and authorization

The owner reprioritized the active offering: archive the synthetic demonstration safely, organize actual source coverage and search, reuse validated domain analysis, and deliver one evidence-backed decision experience through the authenticated MCP surface. This is the active direction; earlier synthetic capability requirements remain historical delivery evidence rather than the current product target. Existing authorization covers implementation without another planning-approval loop. Other Studio, media, provider and human-practice obligations remain open.

Assumptions: reuse existing GCP storage/runtime and organization authority; medallion is an architectural pattern, not a commitment to Databricks services or new paid infrastructure. Bronze is retained original source evidence; silver is validated, typed, traceable facts; gold is a useful decision product over those facts. Data maturity is independent of whether a model has read it.

| Stable capability | Responsibility | Depends on | Existing versus next work |
| --- | --- | --- | --- |
| synthetic-archive | Remove synthetic offering from active discovery while preserving recoverable assets and receipts | — | Explicit archive state and safe routing/config change; no deletion or fallback into real data |
| bronze-discovery | Answer what is held for June 2025, what each source measures, and what is missing | — | Retained inventory exists; add scoped bounded coverage/search product and source references |
| silver-evidence | Validate periods, units, source-local identities and arithmetic; expose original cells | bronze-discovery | Reuse earnings, selections, identity review, changes, audience definitions and receipt readers |
| gold-review | Assemble one catalog review decision packet with evidence, alternatives and next work | silver-evidence | Compose existing resources toward an executable promotion decision; June factual packet is a foundation, not completion of commercial gold; preserve unknowns and scenario assumptions |
| private-mcp | Deliver these products to an authenticated host under current Studio authority | bronze-discovery, silver-evidence, gold-review | Existing service/tool definitions; complete compatible user auth and actual host acceptance |

Build order: archive and bronze-discovery in parallel; bronze-discovery → silver evidence qualification → gold-review → authenticated host acceptance. Authentication implementation may proceed alongside the data work. Neither a synthetic archive nor a green contract run proves private host acceptance.

Detailed spec and implementation tasks: [defiant-medallion-decision.md](defiant-medallion-decision.md). Existing evidence service/provider/runtime/explorer specs remain binding for scope, immutable pins, response limits and source-cell integrity.
