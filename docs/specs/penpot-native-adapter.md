# Penpot native adapter scope

Implements issue54 within the approved editor pathway and shared issue51 schema. Module: operator-workflow; depends on versioned editor contract and future server-owned editor identity mapping. Assumptions: this slice compiles static native boards only, uses explicit installed font bindings, and never grants source, clinical, tenant or final-signoff approval. Existing pilot routes and data are unchanged.

Objective: emit actual Penpot2.18.3 native frames/text/main components and active color-token bindings for both brands and every contract page. Preserve stable logical-layer→UUID mapping, dimensions, source/generation/brand revision and reel timing as provenance (not video). Unsupported cutout/curved-text/animation must remain explicit; required unsupported capability rejects. Official local RPC proofs create disposable QA-owned files only.

Source: new server/penpot-native.js; meaningful Node tests alongside it. Test: `node --test liquidity-studio/server/penpot-native.test.js`. Local reproducer uses fixed loopback39008, external0600 QA credential file, no environment proxy/redirect or credential logging. No dependency, database schema or current application route changes. Code follows existing ES modules and explicit error codes, e.g. `throw new Error('UNSUPPORTED_NATIVE_VERSION')`.

Acceptance: negative schema/version/font/capability tests; native objects have no svg-raw fallback; token themes active and appliedTokens name references resolved to actual fills. Actual local save/get, palette revision propagation, root browser font rendering/native editing, archive/reimport and decoded exports must be recorded separately. Complete native asset archive and Studio authorization integration remain outside this slice; no false closure if fonts/format/archive evidence is incomplete. Always preserve original QA files and reports; never read browser internals or use production credentials. Rollback disables this unused adapter, retaining current exporter and all originals.

Reproduction: compile an accepted issue51 bundle using `compilePenpotNative(bundle,{fileId,fonts})`; fonts are a trusted server-installed manifest with native custom font ID, actual source-byte SHA256, weight/family and retained OFL notice. Hash/license strings are not independently verified by the pure compiler. The local proof separately checks official font-variant records and served original font bytes against repository assets.

The fixed-loopback reproducer is `python3 scripts/investigations/penpot-native-local.py --account-file /private/fixture-accounts.json --evidence-dir /private/native-proof --anchor-file <owned-QA-file> --create-name <fixture-name>`. It creates a new file under the already owned anchor project. Compile to that returned ID, then run the same command with `--compiled /private/compiled.json` instead of `--create-name`. Apply rejects any nonempty revision, other project or file without the QA prefix. The script intentionally omits response bodies/credentials in failures, forbids redirect/environment proxies, and saves full native data only into a private directory. Current proof files predate this reusable wrapper and were created by equivalent explicit local RPC operations.
