For a new durable choice, keep the record short: **Status**, **Context**, **Decision**, **Alternatives/trade-offs**, **Consequences**, and **Evidence**. Use “Proposed” until its decision is actually made; link the issue/PR or approval record. Do not create an ADR for every fix. Existing records are summaries of observable implementation, recorded 2026-10-18, not claims about when the original decision was approved.
