# Liquidity Studio

Local content campaign prototype for The Liquidity Desk.

## Run

Requires Node.js 22+ and Python 3 for the legacy QA evaluator.

```sh
cd liquidity-studio
npm run build
npm start
```

Open http://localhost:3000. The existing application uses an in-memory repository: restarting loses edits, drafts, schedules, and telemetry. Generation can use synthetic content. Export currently records status rather than creating media files. This baseline is not ready for public hosting; admin routes have no authentication.

## Verify

```sh
cd liquidity-studio
npm run test:backwards
npm run qa:loop
```

These checks use local instances and may use synthetic generation; they do not prove cloud integrations or factual accuracy. The served UI is generated by scripts/build-dist.js, separately from src/App.svelte.
