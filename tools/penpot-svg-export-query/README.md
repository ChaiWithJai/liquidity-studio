The [frontend render schema/handler](https://github.com/penpot/penpot/blob/ff7a66f51938b2293260ea27a64e2c4e0833b5e3/frontend/src/app/render.cljs#L151) consumes `:embed`; its existing fontfaces/embedding implementation remains responsible for the actual font bytes.

Copy `server.conf` into the EXISTING owned frontend's `/etc/nginx/overrides/server.d/` configuration hook as `studio-svg-export-query.conf`. Inspect the actual composed Nginx configuration and run its normal syntax check before the owner reloads it. Keep existing routes, proxies, asset access and cookies unchanged. No frontend/backend rebuild, model, account change or new service is needed. Remove only that file and reload to roll back. This repository change alone does not mutate a running gateway.

The redirect applies only to `/render.html` requests with exact delimiter-bounded `render-embed=true` and no existing `embed=` argument. It preserves every argument and adds `embed=true`. Existing explicit choices remain unchanged. A relative browser redirect lets the actual render page observe the new query; an internal rewrite alone does not.
